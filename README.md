# ToyStore Management Frontend

Frontend cho hệ thống bán hàng và quản trị cửa hàng đồ chơi.

## Tech Stack

- React 18
- TypeScript
- Vite
- React Router
- Axios
- Context API
- Tailwind CSS
- Recharts

## Features

- Authentication (JWT, Google Login)
- Product Management
- Shopping Cart
- Order Management
- Admin Dashboard
- Revenue & Order Statistics

## Technical Highlights

- Context API cho Authentication và Cart State
- Axios Interceptors xử lý Access Token
- Protected Routes với React Router
- LocalStorage đồng bộ dữ liệu giỏ hàng
- Recharts cho Dashboard Analytics
- Component tái sử dụng với React + TypeScript
- Responsive UI với Tailwind CSS
